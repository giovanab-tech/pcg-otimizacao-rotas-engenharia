## Descrição do Projeto

Este projeto aborda um problema real de logística na engenharia civil: a otimização do transporte de materiais entre canteiros de obras de forma automatizada.

Para solucionar o problema de Roteamento de Veículos (PRV), implementamos a **Heurística Construtiva do Vizinho Mais Próximo (Nearest Neighbor)**.

## Estrutura do Algoritmo

O algoritmo opera através de:

1. Modelagem Matemática
2. Controle de Estado
3. Loop Aninhado

## Cenários Testados e Validados

* Cenário 1 (3 Pontos): Custo 47 km
* Cenário 2 (5 Pontos): Custo 84 km
* Cenário 3 (8 Pontos): Custo 142 km
